# HTML CSS and Responsive UI

## Workflow
1. Inspect existing design tokens, CSS methodology, breakpoints, and component library.
2. Use semantic HTML elements before custom interactive elements.
3. Build mobile-first layouts and test key viewport widths.
4. Use CSS Grid/Flexbox and logical properties where appropriate.
5. Define focus, hover, active, disabled, and validation states.
6. Respect reduced-motion preferences and color contrast.
7. Check overflow, zoom, text scaling, and long localized content.

## Rules
- Avoid fixed dimensions for content that should reflow.
- Avoid using color alone to communicate state.
- Do not remove visible focus outlines without a clear replacement.
- Use labels and native form controls.
- Keep selectors scoped and avoid escalating specificity.
- Prefer design tokens over scattered magic values.
